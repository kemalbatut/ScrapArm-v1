# ScrapArm-v1
A 4-DOF Arduino-based robotic arm powered by servo motors, built with a scrap-inspired DIY design.


## Features
- 4-axis movement (base, shoulder, elbow, gripper)
- Servo motor control via Arduino
- Modular and simple design
- DIY scrap-inspired build

## Hardware
- Arduino (Uno/Nano)
- Servo motors (x4 or x5)
- External 5V power supply
- Jumper wires / terminal connections
